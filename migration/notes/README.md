# Work-package notes

One note per work package (`<id>.md`): what was ported, acceptance numbers, open problems. New notes go here.

`archive/` holds the notes of finished packages (W1-A .. W5-E, B1 .. B4). Their Helios / PyHelios discrepancies are
folded into `migration/HELIOS_ISSUES.md`; record new ones there directly. File paths inside archived notes are as
they were when written (for example `heliades/parity/ops_plantarch_*.py`, now `heliades/parity/suites/`).
